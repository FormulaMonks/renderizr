# Structurizr Local's diagram editor

Structurizr Local v2026.05.22 edits layout and nothing else. Its diagram editor moves elements (drag, lasso, arrow-key nudges, six align and two distribute commands, centering), sizes the canvas, runs a one-off Dagre layout, and changes each edge's vertices, routing mode, jump-over setting and label position. It saves by sending the whole workspace back every 5 seconds. The fields it writes are element `x` and `y`; relationship `vertices`, `routing`, `jump` and `position`; and view `dimensions`. It deletes `paperSize` when a button grows or shrinks the canvas by 100 units, and every save also writes `views.configuration.lastSavedView`. Undo (`u`) reverts element moves and the bulk commands, skips every per-edge edit and every canvas change, and offers no redo.

## Reading the tables

- **Writes** names fields as the workspace JSON spells them. `x` and `y` live on the view's `elements[]` entries; `vertices`, `routing`, `jump` and `position` live on the view's `relationships[]` entries; `dimensions` and `paperSize` live on the view. "Nothing" means the command changes no field.
- **Undo** says whether `u`, or the "Undo layout changes" button, reverts the change.
- **Edge under the pointer** means the edge the pointer hovers. The editor highlights it, and keys such as `r` act on it.
- **Selection size** matters because the letter keys `l c r t m b h v` align or distribute when the selection holds two or more elements, and do something else otherwise.
- **Title block** means the view's title, description and date line, which Structurizr's renderer draws at the bottom left of the canvas.
- **Source** links the vendored renderer as `diagram.js`, upstream Structurizr files at v2026.05.22 by file name, and JointJS by file name.

## Docs and code disagree

1. The server "Diagram editor" page says `r` toggles routing "between direct, orthogonal, and curved". The code cycles unset → `Direct` → `Curved` → `Orthogonal` → unset, the order the "Structurizr UI" keyboard shortcuts page gives.
2. The "Structurizr UI" editor page describes a dropdown of predefined canvas sizes ("A5 portrait, landscape, etc"). v2026.05.22 has none. The dropdown lived in the archived `structurizr/ui` repository ([controls.jspf](https://github.com/structurizr/ui/blob/3b2582c106f1a836e78696b7226fc5869fe9bad1/src/fragments/diagrams/controls.jspf#L106-L111), [diagrams.jsp](https://github.com/structurizr/ui/blob/3b2582c106f1a836e78696b7226fc5869fe9bad1/src/jsp/diagrams.jsp#L1535-L1544)): a preset set `dimensions` and `paperSize`, and "Canvas size - Custom" deleted `paperSize`. `DiagramEditorController.java` at v2026.05.22 still imports `PaperSize` and never uses it.
3. The same page removes a vertex "by clicking the cross". The code removes it on a double-click, as the server page says.
4. The "Structurizr UI" keyboard shortcuts page maps `n` to "Select all elements by name on the current diagram (case sensitive)". In v2026.05.22 `n` toggles the thumbnail panel. Structurizr's renderer still defines `selectElementsWithName` ([diagram.js:4683](../../vendor/structurizr/js/structurizr-diagram.js#L4683-L4695)), and nothing calls it.
5. That page also maps `p` to presentation mode; in the code `p` opens perspectives and `f` enters presentation mode. That page and the server "Diagram viewer" page both send Left to the next view and Right to the previous one; the code sends Left, Up and Page Up to the previous view and Right, Down and Page Down to the next.
6. The "Structurizr UI" automatic layout page lets the author choose the layout implementation and mentions Graphviz. v2026.05.22 offers Dagre alone.
7. The server "Diagram viewer" page says Alt+double-click on a relationship opens its element link in the editor. The code has no Alt case for it, and in the editor the vertex tool takes every press on an edge before the edge sees it.
