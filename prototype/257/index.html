2. A link into a workspace the set lacks

The landscape's Payments carries url: "{workspace:12}/diagrams", and the build found no workspace for it (it warns). Payments also has a docs property with an https URL in option B, so the menu case shows a second target. Orders crosses normally, for comparison.
